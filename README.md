# Student Marks Analysis

## Description

This project analyzes student marks using Python and calculates
the total, average, highest, and lowest marks.

## Objective

The objective is to practice Python data processing and basic
statistical calculations.

## Tools Used

- Python
- Jupyter Notebook

## Dataset

The project uses manually created student marks stored in a
Python list.

## Approach

1. Store student marks in a Python list.
2. Calculate total using sum().
3. Calculate average using total divided by number of students.
4. Find highest marks using max().
5. Find lowest marks using min().

## Results

- Total Marks: 796
- Average Marks: 79.6
- Highest Marks: 95
- Lowest Marks: 62

## Files

- student_marks_analysis.py
- student_marks_analysis.ipynb
- README.md

## Conclusion

Python provides simple built-in functions such as sum(), max(),
and min() to analyze student marks efficiently.
